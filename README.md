# Sorting Algorithm Visualizer

A modern, interactive web application that visualizes how different sorting algorithms work in real time. Built with React and Tailwind CSS, this application helps users understand sorting algorithms through animations and color-coded visual representations.

## Features

- **Real-time Visualization:** Watch sorting algorithms organize data step by step.
- **Multiple Algorithms:** Supports Bubble Sort, Selection Sort, and Insertion Sort, with an architecture ready for additional algorithms.
- **Speed Control:** Adjust animation speed to analyze each step or accelerate the sorting process.
- **Dynamic Array Generation:** Generate new random datasets with a single click.
- **Color-Coded States:** Easily identify the current state of each element:
  - 🟦 Blue: Unsorted elements.
  - 🟥 Red: Elements currently being compared.
  - 🟨 Yellow: Elements being swapped.
  - 🟩 Green: Fully sorted elements.
- **Responsive Design:** Features a modern dark-mode interface that works across different screen sizes.

## Tech Stack

- **Frontend Framework:** React.js
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
